# SLExt — расширения для SafeLine WAF (CE)

SLExt — набор идемпотентных патчей и собственная вкладка в панели SafeLine, которые
добавляют функции Pro-уровня и полноценную аналитику поверх бесплатной SafeLine WAF (CE).
Никаких обходов лицензии: все возможности реализованы отдельным слоем на nginx, own API и
собственном фронтенде.

## Возможности

| Раздел | Что делает |
|---|---|
| **Обзор** | Анализ реальных атак из журнала SafeLine (без служебных записей), CrowdSec — баны/разбан |
| **Проксирование** | «Золотые сигналы»: RPS, p50/p95/p99, Apdex, ошибки 4xx/5xx, накладные WAF, трафик, уникальные IP, referer, топ путей и медленных запросов |
| **DNS и TLS** | Живые проверки доменов: A/AAAA+TTL, задержка резолвера, SPF/DMARC, TLS-сертификаты (издатель, дни до истечения), автопроверка каждые 5 минут |
| **Зал ожидания** | Вкл/выкл, расписание, детерминированный авто-режим по реальному трафику с журналом решений, своя страница очереди, статистика |
| **Тест ёмкости** | Адаптивный нагрузочный тест (через WAF или напрямую в бэкенд), авто-пауза защиты, подробный отчёт, архив последних 10 запусков |
| **Страницы** | Свои страницы ошибок 403/404/429/465/466/502/504 с редактором и превью |
| **Безопасность** | Skip decryption (аналог Pro) с гейтом первого захода, гео-блокировка по странам |
| **Уведомления** | Telegram, Discord, алерты по метрикам, syslog, автобэкапы |
| **Доступ** | Матрица прав: роли, 22 права, ограничение по доменам — в оригинальном разделе **Settings** панели |

Плюс: собственная тема (тёмная/светлая), скрытие апселлов Pro, экспорт CSV/JSON,
балансировка upstream с health-check, редактор BOT PROTECT-диалога.

## Быстрый старт

**Поверх уже установленной SafeLine CE:**

```bash
gh repo clone Fairen8/slext /tmp/slext && cd /tmp/slext && sudo bash install.sh
```

**На чистом сервере** (сначала официальный инсталлятор SafeLine, затем SLExt):

```bash
gh repo clone Fairen8/slext /tmp/slext && cd /tmp/slext && sudo bash install.sh --with-safeline
```

После установки обновите панель (Ctrl+F5) — в меню появится раздел **SLExt**.

## CI/CD

- `main` — рабочая ветка (PR + 1 одобрение участника);
- **`prod` — деплой: мерж только через PR с одобрением владельца**; после мержа GitHub Actions
  автоматически выкатывает версию на сервер (проверки → tar-over-ssh → `slext-deploy` с бэкапом);
- `main` — стабильная история (как `prod`).

Правила веток включены на GitHub (branch protection + CODEOWNERS). Настройка, флоу и откат —
[docs/ci-cd.md](docs/ci-cd.md), правила для команды — [CONTRIBUTING.md](CONTRIBUTING.md).

## Требования

- Linux x86_64/arm64 с поддержкой **ssse3** (требование SafeLine), systemd, Docker;
- установленная **SafeLine WAF CE** (docker-стек: `safeline-mgt`, `safeline-tengine`, `safeline-pg`);
- `python3` + `psycopg2` (ставится `install.sh` автоматически);
- `openssl` (для TLS-проверок).

## Принципы

- **Без обходов лицензии.** Платные функции не включаются; их аналоги — наш отдельный слой.
- **Идемпотентность.** Каждый патч маркирован (`# slext-*`), повторный запуск ничего не меняет.
- **Вотчдог.** SafeLine периодически перегенерирует конфиги — `slext-apply.path` возвращает
  патчи в течение секунды.
- **Всё локально.** API слушает только `127.0.0.1:8787`; наружу ничего не открывается.
